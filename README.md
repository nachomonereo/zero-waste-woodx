# WOOD-X // Zero-Waste Parametric Furniture & Architectural Studio

**Live Web Application (No Installation Required):**
👉 **[https://nachomonereo.github.io/zero-waste-woodx/](https://nachomonereo.github.io/zero-waste-woodx/)**

WOOD-X is a 100% browser-based Zero-Waste Parametric Furniture & Architectural Studio engineered around standard **122 × 244 cm (`2440 × 1220 mm`)** timber boards with **CNC & Circular Saw Kerf Relative Offsets**, **Multi-Level Architectural Plans & Sections**, and direct **Send to Factory (HERO)** manufacturing dispatch.

## Key Capabilities
- **8 Zero-Waste Parametric Typologies**:
  1. `01 / Modular Sofa & Lounge Chair` (Mortise-and-tenon lock joint)
  2. `02 / Tapered Plank Chair` (199.6×20 cm batch multiplier)
  3. `03 / Vaulted Arch Stool` (9-part interlocking arch + 4 corner shelf gussets)
  4. `04 / Nested L-Leg Table` (7-part concentric table with CNC corner fillets)
  5. `05 / X-Corner Boomerang Table` (3-part zero-waste boomerang X-table)
  6. `06 / Chevron Shelf` (Solid vertical chevron fins + segmented horizontal shelf bays)
  7. `07 / Credenza Cabinet` (Outer frame + 25 mm recessed hinged doors + recessed shelves + rear reinforcement rails)
  8. `08 / Wave Slat Wall` (Complementary sinusoidal slat pairs)
- **CNC & Circular Saw Kerf Compensation**:
  - Computes relative part edge offsets (`-K/2` or `-K`) and deduplicates shared single-pass interior cut lines (`01_CUT_INTERIOR_SHARED`).
  - Auto-tightens 3D assembly joints to `±0.5 mm` post-kerf tolerance so all parts fit accurately after material removal.
- **Architectural Plans & Multi-Level Plan Sections (`mm`)**:
  - Live interactive 2D Top Plan, 3 Horizontal Plan Sections (`A-A`, `B-B`, `C-C`), and 2 Vertical Sections (`D-D`, `E-E`) with 45° section hatching and millimeter cotas.
- **Send to Factory (HERO)**:
  - Packages the 1:1 multi-layer `.DXF`, the A3 Architectural Blueprint (`.PDF` / `.HTML`), and the complete **Material Required & Execution Dimensions Dossier** for dispatch via email to `nacho.monereo@iaac.net`.
